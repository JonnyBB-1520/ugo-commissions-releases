# UGO Commissions — Releases

Installers for **UGO Commissions** by UGO Solutions.

**Download the latest version:** see [Releases](https://github.com/JonnyBB-1520/ugo-commissions-releases/releases/latest) and run `UgoCommissions-Setup-<version>.exe`.

- Installs for the current user only; no admin rights needed.
- Installed copies check this page and offer new versions automatically.
- Every release lists a `SHA256` fingerprint; the app refuses to run an update that doesn't match it.

This repository contains release installers only, not source code.
